# Daily wallpapers and app colors

41 wallpapers rotate continuously, one per local calendar day, anchored to October 1, 2026. UTC arithmetic on local date components avoids DST skips and monthly resets. Ten new beach and Midwest country-field scenes occupy every fourth slot (4 through 40), alternating beach and country. The original 31 scenes and palettes remain intact.

System is the default for missing or invalid preferences and follows each wallpaper. Seven fixed palettes are selectable: blue, green, plum, teal, warm brown, olive, rose/plum. Existing explicit choices remain intact. Colors refresh on resume or within one minute of midnight while visible; Home refreshes when no modal is open. All 41 images are cached for offline rotation.

The new WebP images total 2.03 MiB. Built-in image generation created these assets; original prompts and masters are preserved in the project outputs/wallpaper-review/new-wallpapers directory.
